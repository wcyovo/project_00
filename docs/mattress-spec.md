# 床垫布局与数据规格

> 本文件描述智能床垫的**物理布局**与**数据规格**，是可视化端建模与算法端处理的共同依据。
> 字段、编号、坐标均以本文为准。

## 1. 床体尺寸

- **长 × 宽**：2000 mm × 1800 mm（标准双人床），左右对称。

## 2. 压力数据规格

| 项目 | 规格 |
|---|---|
| 矩阵形状 | **44 行 × 24 列**（row × col） |
| 每帧元素数 | 1056 个 `float` |
| 数据排列 | 行优先：索引 `r * 24 + c` |
| 数值范围（原始） | 0–300（原始读数）；协议层归一化为 0–100 kPa |
| 帧结构 | 单个 `.txt` = 多帧连续序列，帧间空行分隔 |
| 坐标系 | 网格：`x`（列，0–24），`y`（行，0–44）；与布局图 x 0–25、y 0–40 对应 |

## 3. 睡姿类别（sleepPosture）

| 索引 | 文案 | 对应原始动作号 |
|---|---|---|
| 0 | 仰卧 | 1–6 |
| 1 | 俯卧 | 7–9 |
| 2 | 左侧卧 | 10–15 |
| 3 | 右侧卧 | 16–21 |

## 4. 气囊分区（airbags）

共 **8 个气囊**，编号与位置固定：

| 位置 | 编号 |
|---|---|
| 脚部（左右各一，大块） | 12、13 |
| 头部（左半 3 条） | 40、41、42 |
| 头部（右半 3 条） | 64、65、66 |

- 每个气囊：`{ id, level }`，`level` 为充气量百分比 0–100。

## 5. 身体部位划分（bodyRegions）

由 `body_part` 模块的 `BodyPartRegressor` 对压力帧输出 **5 个部位框**：

```
肩 / 背 / 腰 / 臀 / 大腿
```

- 每个部位框：`{ part, x1, y1, x2, y2 }`，坐标 x∈0..24、y∈0..44 的网格矩形。

## 6. 压力指标（metrics）

由可视化端（或算法端输出）实时计算：

| 指标 | 定义 |
|---|---|
| 最大压力 `maxPressure` | 压力矩阵最大值（kPa） |
| 平均压力 `avgPressure` | 压力矩阵平均值（kPa） |
| 接触面指数 `contactIndex` | 压力 > 阈值（默认 10 kPa）的单元数 / 总单元数（1056） |

## 7. 数据文件位置

- 原始压力数据：`data/raw/<用户>/<用户>_<动作号>.txt`
- 示例：`data/raw/SAI/SAI_1.txt`（用户 SAI，动作 1 = 仰卧，含多帧）
